Tools and their clients

Which client opens each tool

Every tool is registered in the identity provider as an OAuth client: when it asks to sign someone in, it presents its client. This table says which group a person must belong to for that sign-in to go through. It is set once, when a tool is added (tools/kaicorp-oidc-cliente.sh); here you check it, or fix it if a tool was re-registered. Roles are not tools: they open pages of this app and have no client.
