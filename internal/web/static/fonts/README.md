# Fuentes autoalojadas

Las mismas tres que LinkUp, copiadas de su repositorio, para que ningún
navegador salga a Google por ellas (`font-src 'self'` en la CSP):

| Fichero | Familia | Licencia |
|---|---|---|
| `spacegrotesk.woff2` | Space Grotesk (Florian Karsten) | SIL Open Font License 1.1 |
| `inter.woff2` | Inter (Rasmus Andersson) | SIL Open Font License 1.1 |
| `jetbrainsmono.woff2` | JetBrains Mono (JetBrains) | SIL Open Font License 1.1 |

La OFL permite redistribuirlas con el software siempre que no se vendan
sueltas y se conserve el aviso; el texto de la licencia está en
<https://openfontlicense.org>.
